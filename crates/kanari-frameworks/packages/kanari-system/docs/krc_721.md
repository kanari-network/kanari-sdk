# Module `0x2::krc_721`

Kanari's collection-bound unique NFT standard. Every production mint and
burn is paired with the matching <code>Collection</code> and <code>NftCap</code>; metadata and
attributes live on the object, while ownership stays in the object runtime.
Issuer modules may wrap <code><a href="transfer.md#0x2_transfer">transfer</a></code> to enforce their own policies.
