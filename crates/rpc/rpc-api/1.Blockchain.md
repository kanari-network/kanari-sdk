# Kanari SDK RPC API Guide

Here are all the available API endpoints and how to call them using curl in Git Bash:

## 1. Blockchain Status
Get current blockchain status:
```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "blockchain_status",
  "params": [],
  "id": 1
}' http://127.0.0.1:30031
```

## 1.1 Blockchain Status
Get all blocks:
```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "get_all_blocks",
  "params": [],
  "id": 1
}' http://127.0.0.1:30031
```

## 2. Get Account
Check account details:
```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0", 
  "method": "get_account_details",
  "params": {
    "address": "YOUR_ACCOUNT_ADDRESS"
  },
  "id": 1
}' http://127.0.0.1:30031
```

## 3. List Accounts
Get all accounts and their balances:
```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "list_accounts",
  "params": [],
  "id": 1
}' http://127.0.0.1:30031
```

## 4. Transfer Tokens
Send KARI tokens (with dynamic gas fees):
```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "transfer",
  "params": {
    "from": "SENDER_ADDRESS",
    "to": "RECEIVER_ADDRESS",
    "amount": 1.0,
    "password": "WALLET_PASSWORD",
    "priority_boost": 5
  },
  "id": 1
}' http://127.0.0.1:30031
```

The `priority_boost` parameter is optional and can be used to increase gas fee for faster processing.
Response includes a unique transaction ID (0x followed by 64 random hex characters) that can be used to track the transaction, along with gas fee details.

## 5. Get Wallets
List all available wallets:
```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "get_wallets",
  "params": [],
  "id": 1
}' http://127.0.0.1:30031
```

## 6. Search Transactions
Search for transactions by address with pagination:
```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "search_transactions",
  "params": {
    "address": "YOUR_ACCOUNT_ADDRESS",
    "limit": 10,
    "offset": 0
  },
  "id": 1
}' http://127.0.0.1:30031
```

## 7. Get Transaction by ID
Look up a transaction using its unique ID:
```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "get_transaction_by_id",
  "params": "0xTRANSACTION_ID",
  "id": 1
}' http://127.0.0.1:30031
```

The response includes transaction details including gas fees, the containing block, and current balances of both sender and receiver.

## 8. Get Gas Fee Info
Get information about current gas fee settings and network congestion:
```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "get_gas_fee_info",
  "params": [],
  "id": 1
}' http://127.0.0.1:30031
```

## Placeholders
Replace these placeholders with actual values when making requests:
- `YOUR_ACCOUNT_ADDRESS`: Your wallet address
- `SENDER_ADDRESS`: Address sending tokens
- `RECEIVER_ADDRESS`: Address receiving tokens
- `WALLET_PASSWORD`: Your wallet password
- `0xTRANSACTION_ID`: Transaction ID (0x followed by 64 hex characters)

## Response Format
Successful response:
```json
{
  "jsonrpc": "2.0",
  "result": {
    // Response data specific to each endpoint
  },
  "id": 1
}
```

Error response:
```json
{
  "jsonrpc": "2.0",
  "error": {
    "code": -32000,
    "message": "Error description"
  },
  "id": 1
}
```

## Transaction Structure
Transaction objects contain the following fields:
- `id`: Unique transaction identifier (0x + 64 hex characters)
- `sender`: Address of the sender
- `receiver`: Address of the receiver
- `amount`: Amount of tokens transferred (in KA units)
- `amount_formatted`: Human-readable amount in KARI
- `gas_fee`: Dynamic gas fee for the transaction (in KA units)
- `gas_fee_formatted`: Human-readable gas fee in KARI
- `timestamp`: UNIX timestamp when the transaction was created

## Gas Fee System
Each transaction has a dynamic gas fee that is:
- Calculated based on network congestion and optional priority boost
- Deducted from the sender in addition to the transfer amount
- Sent to the gas collection address: 0x47621776628ba3a5b9baaab38e61f4c98e893e124204bc4dad52e702e2b24ea1

Gas fees range from a minimum of 0.000000002 KARI to a maximum of 0.000000050 KARI depending on network conditions.

To prioritize your transaction, you can add the optional `priority_boost` parameter when making transfers.
