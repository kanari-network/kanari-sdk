# Kanari Move VM API Guide

Kanari Move VM API ให้บริการ endpoints สำหรับโต้ตอบกับ Move modules บน blockchain, รวมถึงการเรียกใช้ฟังก์ชัน และการสืบค้นข้อมูล modules

## Endpoints

### Execute VM Function

เรียกใช้ฟังก์ชันใน Move module:

```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "vm_execute",
  "params": {
    "module_id": "0x1234::counter",
    "function": "increment",
    "args": [123],
    "gas_budget": 1000000,
    "sender": "0x456",
    "signature": "0xabcdef1234...",
    "signer_address": "0x456"
  },
  "id": 1
}' http://your.node.address:30030
```

#### Parameters

- `module_id` (string): ID ของโมดูลในรูปแบบ `<address>::<module_name>` (จำเป็นต้องระบุ)
- `function` (string): ชื่อฟังก์ชันที่ต้องการเรียก (จำเป็นต้องระบุ)
- `args` (array): อาร์กิวเมนต์สำหรับฟังก์ชัน (ต้องระบุตามลำดับให้ถูกต้อง)
- `gas_budget` (number): จำนวน gas สูงสุดที่ยอมให้ใช้ (ค่าเริ่มต้น: 1,000,000)
- `sender` (string): แอดเดรสของผู้เรียกฟังก์ชัน (ค่าเริ่มต้น: "0x1")
- `signature` (string, optional): ลายเซ็นต์ดิจิทัลสำหรับยืนยันธุรกรรม (เป็นแบบ hex)
- `signer_address` (string, optional): แอดเดรสที่ใช้ในการลงนาม (จำเป็นต้องระบุถ้ามีลายเซ็นต์)

#### Response

```json
{
  "jsonrpc": "2.0",
  "result": {
    "status": "success",
    "tx_id": "vm_tx_0123456789abcdef",
    "module": "0x1234::counter",
    "function": "increment",
    "gas_used": 850,
    "gas_display": "0.0000085 KARI",
    "execution_time_ms": 42,
    "block_height": 1024,
    "timestamp": 1684322600
  },
  "id": 1
}
```

### Get Module Information

ดูข้อมูลเกี่ยวกับ Move module:

```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "vm_get_module",
  "params": {
    "module_id": "0x1234::counter"
  },
  "id": 1
}' http://your.node.address:30030
```

#### Parameters

- `module_id` (string): ID ของโมดูลในรูปแบบ `<address>::<module_name>`

#### Response

```json
{
  "jsonrpc": "2.0",
  "result": {
    "status": "success",
    "module": {
      "module_id": "0x1234::counter",
      "address": "0x1234",
      "name": "counter",
      "deploy_block_height": 42,
      "bytecode_size": 2048,
      "public_functions": ["increment", "decrement", "get_value"]
    }
  },
  "id": 1
}
```

### List All Modules

แสดงรายการโมดูลทั้งหมด:

```bash
curl -X POST -H "Content-Type: application/json" -d '{
  "jsonrpc": "2.0",
  "method": "vm_list_modules",
  "params": {
    "address": "0x1234",
    "limit": 10,
    "offset": 0
  },
  "id": 1
}' http://your.node.address:30030
```

#### Parameters

- `address` (string, optional): กรองตามแอดเดรส
- `limit` (number, optional): จำนวนโมดูลสูงสุดที่จะแสดง (ค่าเริ่มต้น: 100)
- `offset` (number, optional): จำนวนโมดูลที่จะข้าม (ค่าเริ่มต้น: 0)

#### Response

```json
{
  "jsonrpc": "2.0",
  "result": {
    "status": "success",
    "modules": [
      {
        "module_id": "0x1234::counter",
        "address": "0x1234",
        "name": "counter",
        "deploy_block_height": 42,
        "public_functions": ["increment", "decrement", "get_value"]
      },
      {
        "module_id": "0x1234::token",
        "address": "0x1234",
        "name": "token",
        "deploy_block_height": 57,
        "public_functions": ["mint", "burn", "transfer"]
      }
    ],
    "total": 2,
    "limit": 10,
    "offset": 0
  },
  "id": 1
}
```

## ประเภทของอาร์กิวเมนต์ที่รองรับ

- Numbers: ตัวเลขจะถูกแปลงเป็น u64 โดยอัตโนมัติ
- Strings: 
  - หากขึ้นต้นด้วย `0x` จะถูกแปรเป็นแอดเดรส (address)
  - มิฉะนั้นจะถูกแปลงเป็น string (UTF-8)
- Booleans: แปลงเป็น bool (true/false)

## ระบบ Gas

การเรียกใช้ฟังก์ชันใน VM จะมีการคิด gas โดย:
- คิดจากความซับซ้อนของการคำนวณ
- ขนาดของข้อมูลที่เขียนลงใน storage
- สภาวะการคับคั่งของเครือข่าย

คุณสามารถระบุ `gas_budget` เพื่อจำกัดค่าใช้จ่ายสูงสุดสำหรับการเรียกฟังก์ชันได้

## การลงนามธุรกรรม

หากต้องการความปลอดภัยสูงสุด คุณสามารถลงนามการเรียกฟังก์ชันด้วย wallet ได้โดย:
1. สร้าง payload โดยการรวม module_id, function name, และ arguments เข้าด้วยกัน
2. ลงนาม payload ด้วย private key โดยใช้ `mona-crypto`
3. ส่งลายเซ็นต์พร้อมกับ signer_address ในคำขอ API
